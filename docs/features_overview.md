# Features Overview & Scope Guardrail

This document exists to prevent scope creep and to protect daily usability.

---

## Included in v1 (must ship)

### Stock
- barcode scanning
- expiry tracking
- FIFO consumption
- simple locations
- inventory correction
- stock overview dashboard

### Shopping
- shared shopping list
- auto-add below min stock
- auto-remove when stocked
- notes

### Tasks / Chores
- recurring chores
- one-off tasks

### Telegram
- daily expiry summary

### UX
- desktop-first management UI
- Russian and English UI

---

## Postponed (v2+)

- per-chore reminders
- weekly chores summary and shopping-list summary in Telegram
- mobile-friendly web UI
- undo system
- meal planning calendar
- better mobile UX
- bulk operations
- price analytics
- charts
- multi-user permissions

---

## Intentionally dropped

These were removed to reduce complexity and improve adoption:

- tare weight handling
- opened product logic
- freezer/thaw logic
- label printing
- adaptive scheduling
- enterprise permissions
- custom fields system
- plugin system
- generic external API

---

## Optional future ideas (only if needed)

- Telegram commands
- price comparison per store
- kids chores
- gamification
- OCR receipts
- voice input
- native mobile app (unlikely)
